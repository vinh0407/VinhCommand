# Tauri Icons

Place your app icons here:

- `icon.ico` - Windows icon (256x256, 128x128, 64x64, 48x48, 32x32, 16x16)
- `icon.icns` - macOS icon
- `32x32.png` - 32x32 PNG
- `128x128.png` - 128x128 PNG
- `128x128@2x.png` - 256x256 PNG (for Retina)

You can generate these from the `icon.svg` using tools like:
- https://icon.kitchen/
- https://www.favicon-generator.org/
- ImageMagick: `magick icon.svg -resize 256x256 icon.ico`
